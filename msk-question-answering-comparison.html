The three methods

Codex agent with raw files

A Codex agent receives the raw clinical files and column names. It can inspect rows, run code, and consult documentation before giving its answer.

Column names only

The agent receives the question and table and column names. It returns one answer without tools. For numerical questions, it returns SQL that is then executed.

Run with NJ detailed semantic layer

The agent receives the question and relevant parts of the NJ detailed semantic layer: column meanings, measured profiles, table context, joins, and relevant warnings. It returns one answer without tools. For numerical questions, it returns SQL that is then executed.

The dataset

MSK-MET is a cancer dataset that links patients, sequenced tumor samples, molecular measurements and clinical history. This benchmark uses a frozen snapshot with two available raw clinical files. The enrichment describes a wider set of tables.

25,775 patients
25,775 tumor samples
10 described tables
123 described columns
2 queryable raw tables

DATA_CLINICAL_PATIENT holds demographics, age milestones and survival fields. DATA_CLINICAL_SAMPLE holds sample origin, tumor classification, gene panel, molecular measurements and metastasis flags. They join through PATIENT_ID.

Why these questions are difficult

Correct SQL is only part of the task. The answer also needs the right definition, unit, time origin and level of observation.

Different table units

The patient table describes people; the sample table describes sequenced tumors. This snapshot has one sample per patient, verified by keys. Other snapshots can have more samples per person and duplicate patient values after a join.

Survival starts at sequencing

The reviewed meaning of OS_MONTHS starts at first tumor sequencing, not initial diagnosis. Some source text conflicts with that definition. A query can return valid numbers while measuring the wrong time period.

Sample origin versus patient history

A Metastasis sample is tissue taken from a metastatic site. A patient-level metastasis flag records disease history. These concepts cannot be substituted for each other.

Broad anatomical flags

Metastasis flags can cover broad billing-code categories. A head-and-neck label can include a broader respiratory mapping; a biliary label need not isolate bile ducts. Recorded sites do not establish simultaneous onset.

Units and assay differences

TMB is nonsynonymous mutations per megabase, purity is a percentage, and FGA is a genomic fraction. Sequencing coverage is depth. Different gene panels do not guarantee equal detection sensitivity.

Missing and capped values

Missing death age does not establish that a patient is alive. Notes identify age 90 as 90 or older. Missing values, sentinel codes and capped ages need explicit handling.

Several cancer labels

Organ system, broad cancer type, detailed cancer type and OncoTree code serve different purposes. Some detailed labels have several codes, so counting codes can overcount disease categories.

Evidence limits

Only two clinical raw files are available here. Other tables have enrichment metadata but cannot be queried in this benchmark. The clinical files lack treatment exposure, so they cannot establish treatment benefit. Living-only median follow-up is not cohort median survival.

Definitions above summarize the supplied enrichment and verified snapshot. They are not claims that every source note agrees.
